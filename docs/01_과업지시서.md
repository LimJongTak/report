# 과업지시서

## 1. 과업 개요

| 항목 | 내용 |
|---|---|
| 과업명 | 결과보고 자동생성 프로그램(ReportGen) 개발 |
| 발주/운영 | SCNU AIBOOT |
| 수행 방식 | 자체 개발 (VS Code + Claude Code 기반 AI 페어 프로그래밍) |
| 과업 기간 | 착수 후 약 4주 (단계별 마일스톤은 5항 참조) |
| 실행 환경 | 사용자 PC(Windows 10/11 권장)에서 로컬 웹 화면으로 실행 |

### 1.1 추진 배경
- 사업·행사 종료 후 결과보고서를 매번 양식에 맞춰 수작업으로 작성하고 있어 시간이 많이 들고, 작성자마다 문체·분량·구성이 달라 품질이 고르지 않음.
- 기관 표준 결과보고 양식과 과거 결과보고 사례가 축적되어 있어, 이를 기준으로 삼으면 AI가 일관된 초안을 만들 수 있음.

### 1.2 과업 목적
1. 결과보고 양식(.hwpx)과 과거 결과보고서를 **사전 등록(라이브러리화)** 한다.
2. 새 건의 **계획안 + 결과 자료**를 넣으면 양식에 맞는 **결과보고서 초안(.hwpx)과 PDF**를 자동 생성한다.
3. 모든 수치·사실은 **입력 자료에 근거**하고, 근거가 없는 항목은 `[확인 필요]`로 표시하여 허위 기재를 막는다.
4. 작성 시간을 건당 수 시간에서 **30분 이내(검토 포함)** 로 줄인다.

## 2. 과업 범위

| 구분 | 포함 | 제외 |
|---|---|---|
| 입력 | .hwp, .hwpx, .pdf, .docx, .xlsx, .csv, .txt, .md, 이미지(.jpg/.png) | 스캔 이미지 내 손글씨 인식 |
| 처리 | 텍스트 추출, 계획 항목 구조화, 실적 추출, 계획 대비 실적 비교, AI 초안 작성, 근거 표시, 검증 | 회계 시스템 연동, 전자결재 상신 |
| 출력 | 양식 기반 .hwpx, PDF, 근거 보고서(.md) | .hwp(구형 바이너리) 직접 쓰기 |
| 화면 | 로컬 웹 UI(Streamlit) | 다중 사용자 서버 배포, 로그인 |

## 3. 세부 과업 내용

### 3.1 개발 환경 구성
- Python 3.11+ 가상환경, 의존성 관리(`requirements.txt`), `.env` 기반 API 키 관리
- 표준 폴더 구조 생성 (기능정의서 4장 참조), Git 저장소 초기화

### 3.2 라이브러리(사전 자료) 관리 기능
- 결과보고 양식 등록: `.hwpx` 양식 저장, 입력 필드(`{{필드명}}`) 추출, `schema.yaml` 생성
- 과거 결과보고 등록: 텍스트 추출 → 섹션 분할 → 문체 프로필(`style_profile.md`) 생성
- `.hwp` 파일은 `.hwpx`로 변환하거나 텍스트만 추출하여 참고 자료로 활용

### 3.3 신규 결과보고 작성 기능
- 프로젝트(건) 생성 → 계획안·자료 업로드 → 자동 추출 → 계획/실적 구조화
- Claude API로 양식 필드별 초안 생성 (과거 사례 문체 반영, 필드별 근거 파일 표시)
- 필드별 검토·수정·재생성 화면

### 3.4 출력 기능
- 양식 `.hwpx`에 내용 채우기 (일반 텍스트, 표 행 반복, 사진 삽입)
- PDF 변환 (한컴오피스 자동화 우선, 미설치 시 LibreOffice + H2Orestart)

### 3.5 검증 기능
- 미치환 필드, `[확인 필요]` 개수, 근거 없는 숫자, 계획 대비 실적 불일치 점검 후 경고 표시

### 3.6 문서화 및 인계
- README(설치·실행·사용법), 실행용 배치파일(`run.bat`), 양식 추가 가이드

## 6. 검수 기준
1. 등록된 양식으로 생성한 `.hwpx`가 한컴오피스에서 **오류 없이 열리고** 원본 서식(글꼴, 표, 여백)이 유지될 것
2. 생성된 보고서의 **모든 수치가 입력 자료에서 확인 가능**할 것 (근거 보고서로 추적 가능)
3. 근거 없는 항목은 지어내지 않고 `[확인 필요]`로 표시될 것
4. 과거 사례 백테스트 시 담당자 판단으로 **"수정 후 제출 가능"** 수준일 것
5. API 키가 코드·Git에 포함되지 않을 것

## 7. 유의사항
- 참석자 명단 등 **개인정보**는 로컬에만 저장하며, AI 전송 시 이름·연락처 마스킹 옵션을 제공한다.
- Claude API로 전송되는 자료 범위를 화면에 명시한다.
- 양식이 바뀌면 코드 수정 없이 **양식 재등록만으로** 대응 가능해야 한다.
- 구형 `.hwp`는 한컴오피스에서 `.hwpx`로 다시 저장해 등록하는 것을 원칙으로 한다.
