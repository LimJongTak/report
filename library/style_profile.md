# 문체 프로필 (결과보고)

## 1. 코드 통계 (자동 계산)
- 분석 사례: 3건 (2026 바이브코딩경진대회, 네이버클라우드 사옥투어 현장견학, 메가존클라우드 사옥투어 현장견학)
- 분석 줄 수: 195, 줄당 평균 40.7자
- 문장 끝 유형: ~함/~임 (개조식) 10회, ~하였습니다/~되었습니다 (서술형) 17회, 명사형 종결(~제고, ~강화) 24회, ~필요 2회
- 줄머리 기호: '-' 12회
- 날짜 표기 예: 2026. 07. 10.(금), 2026. 07. 16. → 표준: 2026. 07. 10.(금)
- 금액 표기: 천 단위 쉼표 사용(3회), 표 안에서는 '원' 생략

## 2. 문서 구성 (과거 결과보고 8건 분석 — 초기본, API 연결 후 자동 갱신)
- 맨 위 제목 상자: 1줄 「사업단명」, 2~3줄 행사명 + "결과보고"
- 장 제목은 번호 상자(Ⅰ, 2, 3 … 또는 1, 2, 3)와 장 이름: 사업개요/추진목적 → 프로그램(행사) 개요 → 주요 추진내용·세부 일정 → 운영 성과 → 향후 활용계획 → 소요예산 → 행사 사진
- 장 안에서는 '○ 소제목' 아래 '- 세부 항목' 2단 구조. 운영 성과 장은 '1. 소제목', '2. 만족도 조사 결과'처럼 번호 소제목 사용
- 표: 머리행은 진한 남색 바탕 흰 글씨. 운영일정(날짜/시간/내용/비고), 만족도 조사 현황(구분/내용), 예산(예산과목/세부항목/산출내역/금액)

## 3. 어미·문장
- 추진배경·추진목적·주요 추진내용: 개조식. '~필요', '~하고자 함', '~제고', '~강화', '~확대', '~마련' 같은 명사형 종결. 한 항목 1~2문장
- 운영 결과·만족도 분석: 서술형 '~하였습니다', '~마련하였습니다', '~도출되었습니다', '~분석되었습니다', '~파악됩니다', '~확인되었습니다'
- 주요 성과: 한 줄 명사형('~역량 향상', '~의지 고취', '~모델 구축', '~자긍심 확보'). 경진대회형은 '소제목: 설명 ~함' 형식도 사용
- 향후 활용계획: 짧은 소제목(교육과정 고도화, 실무 프로젝트 역량 강화, 취업연계 강화) + 1~2문장 '~강화합니다/~지도합니다/~활용합니다'

## 4. 기호·숫자·날짜 표기
- 날짜: '2026. 07. 10.(금)' (월·일 두 자리, 요일 괄호). 기간: '2026. 08. 31. ~ 09. 04.'. 조사기간 표에서는 '2026. 7. 13. ~ 7. 20.'도 사용
- 시간: '13:00~14:00', '10:00-17:40'
- 금액: 천 단위 쉼표, 본문은 '금 1,281,640원', 표 안은 '원' 생략하고 '(단위 : 원)' 표기
- 인원: '20명', '총 49명(1인 1작품 출품)'
- 행사 개요 줄 맞춤: '행 사 명 : ', '행사일시 : ', '장    소 : ', '대    상 : '
- 재원 줄: ' ◦ 재원 – AI인재양성부트캠프 사업비 : 금 ○원'

## 5. 필드별 분량 가이드
- 추진배경 2~3항목(각 60~90자), 추진목적 2~3항목(각 60~110자)
- 주요 추진내용 2~4항목(각 30~60자)
- 운영 결과 1문단 2~3문장(150~250자)
- 만족도 요약 1문단(100~180자), 문항별 분석 1~2문장(60~120자)
- 주요 성과 3~4항목(각 30~60자)
- 향후 활용계획 2~3개(소제목 + 70~120자)

## 6. 자주 쓰는 표현
- 현장 중심 실무 교육, 산학 연계성 강화, 실무 역량 강화, 진로 로드맵 설계, 취업 연계, 동기부여, 성취감 고취, 학업 성취도 고취, 산학 밀착형 교육 모델
- 만족도: '매우 그렇다(80%, 16명), 그렇다(15%, 3명)로 응답자의 95%가 긍정적으로 평가하여 ~'
- '~에 대해 매우 긍정적인 평가가 도출되었습니다'

## 7. 피해야 할 표현
- 근거 없는 최상급·과장('최고의', '완벽한', '획기적인')과 자료에 없는 수치
- 구어체('~했어요'), 1인칭('저희')
- 한 문장 안에 개조식 어미와 서술형 어미 혼용

## 8. 필드별 모범 문단 (과거 보고서 인용)
- 추진배경: "기업 사옥을 직접 방문함으로써 산학 연계성을 강화하고, 학생들에게 실제 산업 현장의 기술적 시야를 넓혀줄 기회를 제공하고자 함"
- 추진목적: "참여 기업 현업 전문가의 멘토링을 통해 프로젝트의 완성도를 높이고, 실제 현장에서 요구하는 핵심 기술 스택과 직무 노하우를 공유받아 학생 개인별 실무 문제해결 역량과 진로 경쟁력을 강화"
- 운영 결과: "최첨단 AI·클라우드 기업 네이버 1784 사옥 견학 및 현업 전문가 멘토링을 통해, 학생들이 전공 교육에서 배운 이론과 실무 프로젝트가 실제 산업 현장 인프라와 비즈니스에 어떻게 적용되는지 직접 확인하고 실무 역량을 강화할 수 있는 기반을 마련하였습니다."
- 만족도 요약: "현장견학에 참여한 20명의 응답자를 대상으로 만족도 조사를 실시한 결과, 전반적인 프로그램 구성과 진로 동기부여 측면에서 매우 긍정적인 평가가 도출되었습니다."
- 문항 분석: "매우 그렇다(80%, 16명), 그렇다(15%, 3명)로 응답자의 95%가 긍정적으로 평가하여 실질적인 기술 이해도 제고에 성공적이었음이 분석되었습니다."
- 주요 성과: "현업 전문가와의 멘토링을 통한 직무 핵심 역량 파악 및 취업 의지 고취"
- 향후 활용계획: "교육과정 고도화 — 현장견학을 통해 파악한 최신 산업 트렌드 및 실제 현장에서 요구하는 핵심 기술 스택을 반영하여, AI·클라우드 실무형 교육과정의 내실을 강화합니다."
